# Smart-Desk-System

Comprehensive project for managing smart desk functionalities, including backend, frontend, and AI service components.

## Project Structure

- **backend**: Contains the Java Spring Boot backend.
- **frontend**: Contains the React frontend.
- **ai-service**: Contains the AI service for processing and analytics.

## Installation

1. Clone the repository
2. Navigate to the backend and run `./gradlew bootRun`
3. Navigate to the frontend and run `npm start`
4. Start the AI service in the specified directory.
